# Transformers Armada PS2 Mods: the mod list

Mods here are made for the **decompiled version** of the game: the PC version that will be built from the
decompilation. Versions for the recompiled build or for PS2 emulators are not planned, unless many people ask for them.

Every mod is optional and off by default, so the original game is always one step away. Randomizers will be seeded,
so a seed can be shared and played again.

## First mods

These already run in a recompiled build of the game (see the screenshots on the main page) or were tested in the
game, and will be the first ones made for the decompiled version.

| Mod | What it does |
|---|---|
| 🖼️ **Ultrawide** | 16:9, 21:9 and 32:9: more of the world at the sides, the HUD moved out to the screen edges |
| 🔭 **HD and 4K** | Rendering at high internal resolutions with sharp edges and clean text |
| 🛠️ **Hidden options** | The game's own config file still has options the menus never show. Tested in the game: god mode, a level select that loads any level, and the warp gate transitions |
