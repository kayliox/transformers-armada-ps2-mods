# Transformers Armada PS2 Mods: all 32 cheat codes

Decoded from the game's own table of codes, which is the same in the European (SLES-52388) and North American
(SLUS-20668) versions. Enter a code with the buttons in the order shown, on the screen it belongs to.

**How we know** says how sure each line is:
- **tried in the game**: entered on a real copy of the game and the effect seen;
- **publicly known**: already on public cheat lists, and its use found in the code;
- **read from the code**: what the game's code does with it; not tried yet;
- **unknown**: the code works, but what it changes has not been found yet.

The 15 difficulty-screen codes build on each other: each one includes everything the one before it unlocks.
